## Функциональная проверка

- Owning Go-проверки: read-only архив и браузерные границы, parser validation, сохранение last-good, persisted origin cooldown и restart. Проверены malformed числа, NaN/Inf, неизвестная схема и потерянный optional archive. go vet пройден; Linux race tests пройдены в финальной CI-сборке.
- Windows installer реально установлен в CI в отдельный каталог; установленное приложение ответило правильной версией через local API. Linux .deb реально установлен, desktop-процесс запущен в Xvfb и завершён штатным SIGTERM.
- На Windows-ПК отдельный процесс с треем запустился и отвечал local API на синтетическом состоянии. Пиксели нативного меню трея: NOT_VERIFIED, безопасная оконная поверхность Cua не предоставила системный трей/скрытое окно приложения для снимка. Не считать это визуальной проверкой меню.
- Полный исследовательский SQLite подключён через реальный Go UI только для чтения. Контрольный поиск дал ожидаемые 578 конкурсов примерно за 0,6 секунды. Среда локальной проверки: Windows, Go 1.26.0; CI-пакеты собраны Go 1.25.x. Время является наблюдением одного запроса, не SLA.
- Web UI приложения проверен на синтетических данных при 1440 px и 390 px: наблюдение, история, поиск, настройки, форма добавления и первый запуск. Настольные и мобильные изображения непосредственно просмотрены. Опубликованный лендинг тоже просмотрен в обоих размерах; изображения содержат только учебные данные.

## Данные и сохранность

Новый SQLite: 1 285 824 512 байт, 207 697 конкурсов, 22 070 303 строки заявлений, 2 461 350 связанных годовых записей ID. Это не количество уникальных людей между годами.

Проверены whitelist пяти таблиц, два представления, отсутствие auth/operational-таблиц и свободных страниц, ссылки, формат ID и counts. Полный integrity_check вернул ok за 24,28 секунды с 128 МиБ кэша. Первую медленную read-only проверку с маленьким default cache остановили без изменения готового файла; экспортёр исправлен, self-check повторно прошёл. Файл не пересоздавался и не очищался удалением таблиц.

SHA-256 оригинального архивного источника до/после совпал: `f8e8f61642586c0f418f46d7886942937c75a2b12fa56b68a25a82ddd5762200`. Gzip round-trip SHA-256 совпал с проверенным SQLite. SHA-256 gzip: `ee286b4dad145f445cdd2b53270449c1a0505650d05390a8c14eb2e9a52edb90`.

Исторические исходные файлы, SQLite, ZIP и журналы сохранены; резервные копии, удаления и переписывание истории не выполнялись. Старый Python-код оставлен как неподдерживаемое исследовательское наследие, новый runtime не требует развёртывания платформы.

## Границы результата

- Живой источник Госуслуг и robots.txt при одиночной проверке с ПК ответили тайм-аутом. Live-сбор сейчас NOT_VERIFIED; тесты parser-контракта не заменяют проверку актуальной схемы сервиса.
- Месяцы непрерывной работы не наблюдались. Проверены механизмы восстановления, ограничений и bounded history; обещание длительного SLA не даётся.
- MIT относится к коду. Юридическая лицензия источника на повторное распространение массива не установлена; ограничения и права третьих лиц описаны в DATA.md.
- Пиксели нативного трея NOT_VERIFIED. Web UI самостоятельно просмотрен и доставлен инициатору; явное визуальное согласование закрытия ожидается по owner policy. Публикация уже разрешённого результата выполнена независимо от этого согласования.
