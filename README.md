# Vvuzz

Ваше место в общей картине поступления. Бесплатный локальный инструмент для студентов и исследователей.

Vvuzz 0.0.1 — Go-приложение с web-интерфейсом и треем для Windows и Linux. Оно наблюдает за выбранными публичными конкурсными списками, сохраняет изменения и помогает исследовать исторический архив. Аккаунт, подписка и наш сервер не нужны. В программе нет телеметрии.

[Скачать 0.0.1](https://github.com/LeoTechPro/Vvuzz/releases/tag/v0.0.1) · [История проекта](https://intdata.pro/vvuzz/) · [Данные и происхождение](docs/DATA.md)

## Быстрый старт

**Windows x64:** запустите `vvuzz-0.0.1-windows-amd64-setup.exe`. Установка производится в профиль пользователя без прав администратора. Запустите Vvuzz из меню «Пуск», затем выберите «Открыть Vvuzz» в трее. Автозапуск при входе включается отдельным флажком установщика.

**Debian / Ubuntu x64:**

```sh
sudo apt install ./vvuzz-0.0.1-linux-amd64.deb
vvuzz
```

Для GNOME может понадобиться расширение AppIndicator. Требуются GTK 3 и libayatana-appindicator3. Для других дистрибутивов есть tar.gz и отдельный бинарник без трея.

Интерфейс работает по адресу **http://127.0.0.1:9177**. Закрытие вкладки не завершает процесс. Завершение через меню трея останавливает наблюдение.

## Что можно делать

- Добавить публичную ссылку Госуслуг на конкретный список `applicants` / `ratings` и свой ID, задать название и количество мест.
- Следить за местом, размером списка и количеством согласий выше вас в этом конкурсе.
- Смотреть историю изменений. Сохраняются последние 2 000 изменившихся наблюдений каждого списка; в интерфейсе показываются последние 100.
- Подключить нормализованный исторический SQLite в настройках и искать ID по конкурсам 2025/2026. Архив открывается только для чтения.
- Приостанавливать и продолжать наблюдение из интерфейса или трея.

Снимки не гарантируют зачисление. ID из разных кампаний не означает одного человека. Отсутствие согласия в собранной части данных не означает отсутствия согласия вообще.

## Данные остаются у вас

Состояние находится в `%APPDATA%/Vvuzz` на Windows и `$XDG_CONFIG_HOME/Vvuzz` (обычно `~/.config/Vvuzz`) на Linux. Архив может лежать отдельно. Удаление приложения не удаляет собранные данные пользователя.

```sh
vvuzz --archive /полный/путь/vvuzz-admissions-2025-2026.sqlite
vvuzz --data /полный/путь/моё-состояние --port 9177 --no-tray
vvuzz --version
```

После распаковки исследовательского `.sqlite.gz` укажите путь к `.sqlite` в настройках. Архив не встроен в установщик: приложение можно использовать без загрузки большого набора.

### Автозапуск Linux

Для установленного .deb в графическом сеансе:

```sh
systemctl --user enable --now vvuzz.service
```

Или добавьте `vvuzz` в автозапуск своего рабочего стола. Выберите один способ, чтобы не запускать два экземпляра. Для headless используйте отдельный бинарник с `--no-tray` под собственным process manager; не открывайте локальный порт наружу.

## Бережное обновление

Один последовательный worker выполняет не более пяти запросов в минуту на всё приложение. Каждый выбранный список проверяется не чаще раза в 30 минут. При 401/403/429 действует общая пауза источника не менее трёх часов с учётом `Retry-After`; она переживает перезапуск. Остальные сетевые ошибки получают увеличивающуюся задержку. Таймаут — 25 секунд, ответ — не более 16 МиБ, не более 50 выбранных списков.

Vvuzz не обходит CAPTCHA, авторизацию или блокировки, не меняет IP и не перебирает ID конкурсов. Перед включением наблюдения проверьте актуальные правила источника. Доступность endpoint и исторический опыт не являются разрешением сервиса. Адаптер navigator-ссылок рассчитан на кампанию 2026; для другого года нужна проверка схемы. Текущее состояние сервиса после сезона не обещано.

## Сборка и проверки

Go 1.25 или новее. Windows-сборка не требует CGo; Linux-трей требует GCC, pkg-config, GTK 3 и libayatana-appindicator3 development headers.

```sh
go test -tags headless ./...
go vet -tags headless ./...
go build -trimpath -o vvuzz ./cmd/vvuzz
# Linux без GUI-зависимостей:
CGO_ENABLED=0 go build -tags headless -o vvuzz-headless ./cmd/vvuzz
```

Windows без консольного окна:

```powershell
go build -trimpath -ldflags '-s -w -H=windowsgui' -o dist/vvuzz.exe ./cmd/vvuzz
```

Workflow `.github/workflows/release.yml` собирает Windows installer и Linux .deb/tar.gz. Он создаёт артефакты, но не публикует релиз автоматически. Планируемый открытый выпуск только **0.0.1**; будущие релизы и сопровождение не обещаны. Стабильность в течение месяцев не подтверждается коротким smoke-тестом.

## Что мы открываем

Около трёх месяцев летом проект работал на личном компьютере и сервере автора. Вместо размещения ещё одной платформы мы отдали инструмент и результаты своей работы сообществу. В архиве сохранено 207 697 конкурсных групп и 22 070 303 строки заявлений за две кампании. Это частичный исторический сбор, не официальный реестр.
